# v0.5.1 发布准备（未发布）

**状态：v0.5.1 尚未发布。** 本页是 [Issue #502](https://github.com/Luo-root/pulse/issues/502) 的发布准备说明，不代表 tag、GitHub Release 或模块已可下载。默认安装继续固定已发布的 v0.5.0，待 v0.5.1 实际可用后再更新。

## 兼容性影响：最低 Go 升级

当前源码及计划中的 v0.5.1 将最低 Go 版本从 v0.5.0 的 **Go 1.25.0+** 提升到 **Go 1.26.0+**，与 Durable 统一。根模块及独立 DAG 评测模块均声明 `go 1.26.0`。

这是工具链兼容性变化，不能表述为完全向后兼容：固定使用 Go 1.25、禁用自动工具链选择的环境不能直接构建新版本。升级前应在开发机和 CI 中选用 Go 1.26.0 或更高版本，并按应用需要更新其 go.mod/go.sum。

本次调整不改变公开 API、工作流运行语义、检查点桥契约或 Core / Durable 的职责边界；不是一次执行引擎功能改造。v0.5.0 发布说明和迁移页中的原工具链要求、历史性能报告及测试工具链记录保持原样，不作为 Go 1.26 的验证结果。

## 安装与验收

- 当前默认安装仍为 `go get github.com/Luo-root/pulse@v0.5.0`，其原最低要求是 Go 1.25.0+。
- 试用本次未发布修改时，按[安装页](../guide/installation.md)使用匹配的本地源码，不能假设 main 已包含此改动。
- 发布前应在最终候选提交上完成 Go 1.26 的 build、vet、race、文档签名门禁和站点构建；具体通过情况以实际执行记录为准，本页不预先宣称通过。
- 新性能数据只能来自对应工具链下的实际重测；本次工具链升级不追溯改写历史数据。
- 合并、打 tag 和创建 Release 由维护者决定；准备说明不触发发布。
