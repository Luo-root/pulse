# Pulse v0.5.1 发布说明

**状态：v0.5.1 已发布。** 本页记录 Go 1.26+ 基线、兼容性影响和正式 SQLite 测量入口；安装请使用 `go get github.com/Luo-root/pulse@v0.5.1`。

## 兼容性影响：最低 Go 升级

v0.5.1 将最低 Go 版本从 v0.5.0 的 **Go 1.25.0+** 提升到 **Go 1.26.0+**，与 Durable 统一。根模块及独立 DAG 评测模块均声明 `go 1.26.0`。

这是工具链兼容性变化，不能表述为完全向后兼容：固定使用 Go 1.25、禁用自动工具链选择的环境不能直接构建新版本。升级前应在开发机和 CI 中选用 Go 1.26.0 或更高版本，并按应用需要更新其 go.mod/go.sum。

本次调整不改变公开 API、工作流运行语义、检查点桥契约或 Core / Durable 的职责边界；不是一次执行引擎功能改造。v0.5.0 发布说明和迁移页中的原工具链要求、历史性能报告及测试工具链记录保持原样，不作为 Go 1.26 的验证结果。

## 安装与验收

- 正式安装：`go get github.com/Luo-root/pulse@v0.5.1`；最低要求为 Go 1.26.0+。
- v0.5.0 仍可按原 tag 安装，其最低 Go 要求为 1.25.0+；不要把旧版本工具链要求当作 v0.5.1 要求。
- 最终候选已完成 Go 1.26 的 build、vet、race、文档站构建及 CI 检查；站点构建保留 chunk 体积 warning，不影响生成。
- 当前正式测量见[正式版 SQLite 与恢复测量](./sqlite-formal-20261023.md)，状态必须按 `COMPLETED_WITH_ERRORS` 阅读；它不替换完整历史证据，也不把未测点补成成功。
- Pulse Core 与 Pulse Durable 独立发布；本页只描述 Core v0.5.1。
